# QGEN — Public technical status / disclosures

**The linked website is a functional demo only. Not a working Quark mint.** No wallet signs, no QTC is accepted, no Quark is created and no creator fee is collected.

- QGEN is independent and is **not affiliated** with or endorsed by Quantus or Qlyphs.
- The 256-edition limit belongs to QGEN's **offchain manifest/registry**. Quarks as a protocol are not capped at 256, and third parties can inscribe identical artwork. An edition number (QGEN #001) is not a native Quark sequence number.
- Displayed traits and artwork currently use **simulated Quantus blocks**; real finalized mainnet block inputs and the collection manifest have not been frozen. Preview and sample rarity are not a claim of financial value.
- Reactor/mystery generation is a **visual demo**, not cryptographically hidden reveal; a collector should inspect the exact SVG before signing.
- The proposed creator charge is **approximately US$3 equivalent in QTC** *in addition to* Qlyphs and network fees, only if an approved, disclosed, wallet-confirmed payment mechanism becomes available. No fee is currently taken. Fees, exchange rates and onchain block schedule remain unverified at live checkout.
- Qlyphs origin approval, an atomic inscription-plus-creator-fee method, trusted chain/indexer receipts, persistent registry, real wallet QA and a capped mainnet smoke test remain outstanding. Without these, **paid minting stays disabled**.
