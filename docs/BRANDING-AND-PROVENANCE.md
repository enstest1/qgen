# QGEN branding and chain DNA

Public project name: **QGEN**. GitHub: `enstest1/qgen`. Railway project: `qgen` (stable project ID `ab434856-426c-4ba6-8d2a-d777f1943adf`). Demo URL: https://qgen.up.railway.app/ .

**Important:** The original QG1 cryptographic domain-separation string `QUANT//GENESIS|QG1|` in `src/engine.mjs` remains unchanged. It is part of the versioned generator's provenance and avoids altering the content hashes of all 256 already-generated demo examples. Do not change without a deliberately versioned `QG2` migration.

Public minting remains disabled. The current website is a reduced read-only Railway Function preview, not the GitHub-connected Node app. This repo provides the complete candidate website and backend for developer review and future source-based Railway deployment.
