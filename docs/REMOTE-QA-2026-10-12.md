# Independent Railway preview QA — October 12, 2026

This report applies to the **separate read-only Railway Function** at
https://qgen.up.railway.app/ — not the unreleased full Node/SQLite application in this source tree.

## Completed tests on authorized Windows computer

- `GET /api/health`: HTTP **200**, JSON `{ok:true,environment:'demo',mintReady:false,chainSource:'simulated',wallet:false}`.
- HTML: HTTP **200**, proton reactor hero present and read-only labeling.
- **256/256** SVGs fetched over HTTPS and compared against the returned `/api/art/:edition` SHA-256 and byte count; **256 unique** SHA-256 hashes, maximum **926 bytes**.
- Negative tests: edition 257 returned HTTP **404**; POST to read-only mystery route returned **405**.
- Chrome headless desktop screenshot taken on Windows; a literal Unicode-escape issue was found and repaired. The subsequent HTML fetch confirmed correct `✳`, `≤ 960B`, and `↗` characters.
- Chrome headless mobile screenshot identified horizontal overflow in the reduced preview; CSS correction was deployed successfully; a follow-up Chrome headless mobile-size screenshot confirmed the headline, reactor and controls fit within the tested captured width. Header badge may still overflow in Chrome CLI small-width screenshots due to its minimum desktop viewport; dedicated device emulation remains a separate QA gate. This **does not** validate the production Node source or a real browser/wallet.

## Excluded / not yet proven

- Full Node GitHub-connected build on Railway, real Quantus finalized block anchor, Quark inscription proof and creator payment.
- Connected wallet popup behavior, native transaction contents, failed QLYP execution, reorgs and unknown-broadcast retries.
- Cross-browser accessibility, mobile Safari and Android wallets, multi-instance DB locking and security audit.

**Decision:** Public read-only visual preview suitable for developer review. Real-money mainnet release is blocked by published wallet constraints and chain verifier integration.
